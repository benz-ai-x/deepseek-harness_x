# Agent Note: 强制校验成员必需的协作能力

Status: implemented

[English](2026-09-08-enforce-required-member-collaboration.md) | 中文

## 问题

提供方可以为新原生会话安装全部 Team 操作，而已有会话仍保留较少操作。只检查目录会允许精确句柄无法提供的显式必需能力。

## 决策

运行时注册表在接受 create 或 resume 前，使用精确句柄的操作证明校验规范化请求。`full-collaboration` 需求要求全部六项操作；缺失证明不能满足该需求。失败复用现有结果违约隔离与完全停稳清理，撤销受影响的提供方世代，但不退役其他提供方。保留的 roster 和 mailbox 事实允许新注册在提供完整证明后恢复同一身份。

## 考虑过的替代方案

**只使用目录。** 拒绝，因为目录描述提供方支持的能力，而不是一个持久句柄上已安装的操作。

**只降低 Studio 的显示等级。** 拒绝，因为直接 Host 调用方也需要强制校验，且不能向恢复后不兼容的句柄投递排队工作。

**无条件拒绝有限会话。** 拒绝，因为不要求完整协作的请求可以合法保留有限或未知操作，包括无法证明工具集的冷恢复。

## 影响

显式完整协作需求默认拒绝不满足条件的结果，不新增持久字段，也不替换原生身份。违约世代清理后必须重新注册；原注册不能复用。公开 Team 测试覆盖创建证明不足、精确句柄恢复拒绝、排队投递、其他提供方不受影响，以及不创建另一原生会话的恢复。
